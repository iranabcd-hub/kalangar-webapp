# کالانگار — وب‌اپ آفلاین‌اول (PWA)

- مدیریت کاتالوگ، محصولات، مشتریان، پیش‌فاکتور/فروش، گزارش‌ها (Pro)، کاتالوگ عمومی، تنظیمات، مشاور هوشمند (Gemini)
- تم نارنجی/قرمز، حالت تیره/روشن، شیشه‌ای ظریف
- ذخیره‌سازی محلی (IndexedDB)، پشتیبان‌گیری JSON، نصب‌پذیر به‌عنوان اپ (PWA)

## اجرا
- یک وب‌سرور ساده اجرا کنید (برای SW لازم است):
  - Node: `npx serve dist`
  - Python: `cd dist && python -m http.server 8000`
- باز کنید: http://localhost:8000 یا آدرس سرور شما.
